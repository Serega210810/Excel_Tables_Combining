# 📊 Excel Tables Combining & Financial Analyzer

Набор Python-инструментов для автоматизации обработки, объединения и анализа финансовых Excel-отчётов. Проект решает реальные бизнес-задачи: от сведения годовых расходов компании до сложного анализа фонда оплаты труда (ФОТ) с учётом аномалий в данных.

## 🚀 Возможности

Проект состоит из двух независимых модулей:

### 1. 📈 Анализ годовых расходов компании (`financial_year_report`)
* Автоматическое объединение 12 ежемесячных Excel-файлов в одну сводную таблицу.
* Умная сортировка всех операций в хронологическом порядке.
* Автоматический расчет ширины колонок для удобного чтения в Excel.
* Обработка "грязных" данных и пропуск повреждённых файлов без остановки скрипта.

### 2. 💰 Анализ зарплат и ФОТ (`yearly_salary_summary`)
* **Надёжная группировка по ID сотрудника**, а не по имени (защита от полных тёзок).
* **Нормализация ФИО**: автоматическое приведение разных форматов записи (например, "Иванов И.И.", "И. Иванов", "Иванов Иван Иванович") к единому стандарту.
* **Визуальная сверка**: все варианты написания ФИО для одного ID выводятся через разделитель `||` для ручного контроля.
* **Детектор аномалий**: автоматическое предупреждение, если на один и тот же ID в разное время были записаны разные люди (например, из-за ошибки кадровика или переиспользования ID).
* **Умный расчёт**: автоматический подсчёт отработанных месяцев, месяцев на больничном (с учётом даты трудоустройства) и средней месячной зарплаты.

## 🛠 Технологии

* **Python 3.8+**
* **pandas** — для чтения, очистки, группировки и агрегации табличных данных.
* **openpyxl** — для сохранения результатов в Excel и программной настройки ширины колонок.
* **re** — для регулярных выражений при нормализации текстовых данных (ФИО).
